# Getting started

Open `16th_note-Imported` in WPILib VS Code with the WPILib 2026 Java 17 toolchain. Team number is 9924.

Xbox USB 0: left Y drives, right X turns. RT/LT run intake forward/reverse; RB/LB run indexer forward/reverse. A/X select shooter 50%/75% free speed; B stops it. POV Down/Right/Up select pivot +90/+15/-60 degrees. Start with the intake physically home at +90 degrees. CAN 1/2 drive, 3 indexer, 5 pivot, 6 intake, 7 shooter. Autonomous offers Do nothing.

Run `./gradlew.bat build`, `./gradlew.bat simulateJava`, or `./gradlew.bat deploy`. On Linux/macOS use `./gradlew`.
